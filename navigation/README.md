# Robot Navigation — BXI_ELF3 Bipedal Walking

基于 ONNX 行走策略的机器人导航模块。从当前位姿走到目标点，使用纯反馈控制（无路径规划），实时计算速度指令驱动 RL 策略。

## 快速使用

```bash
# 可视化导航到默认目标 (0, 0.5)
python navigation/navigate.py

# 指定目标
python navigation/navigate.py --tx 2.0 --ty 1.0

# 无头模式（单次）
python navigation/navigate.py --tx 1.0 --ty 0.5 --headless

# 15 目标测试集
python navigation/navigate.py --test

# 50 目标全向测试集（近→远）
python navigation/navigate.py --test50
```

## 控制算法

### 整体架构

```
目标 (tx, ty)
     │
     ▼
┌─────────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│  Navigator   │ ──► │ 低通滤波  │ ──► │ cmd[3]   │ ──► │ ONNX     │
│  update()    │     │ α=0.7    │     │ vx,vy,ω  │     │ Policy   │
└─────────────┘     └──────────┘     └──────────┘     └──────────┘
     ▲
     │  (x, y, yaw)
     │
┌─────────────┐
│ get_robot_  │
│ pose(env)   │
└─────────────┘
```

### 状态计算

每一帧从 MuJoCo 中提取机器人位姿：

```
dx = target_x - robot_x
dy = target_y - robot_y
distance = √(dx² + dy²)
target_heading = atan2(dy, dx)
heading_error = normalize_angle(target_heading - robot_yaw)
```

### 控制模式

Navigator 有三种工作模式，按优先级排列：

#### 1. 到达模式

```python
if distance < arrival_threshold:  # 0.10m
    cmd = [0, 0, 0]  # 停止
    arrived = True
```

#### 2. 原地转身模式（大角度偏差）

当 `|heading_error| > 60°` 时，机器人与目标方向差距过大。此时前进只会形成环绕轨道，永远无法收敛到目标。

```python
if |heading_error| > 60°:        # 进入阈值
    vx = 0                        # 不前进
    ω = turn_speed × sign(heading_error)  # 原地旋转

# 迟滞退出：对齐到 45° 以内才恢复行走
if _in_turn_in_place and |heading_error| < 45°:
    exit turn-in-place
```

**迟滞设计**（60° 进入 / 45° 退出）防止振荡：对于后方近距离目标，行走会改变目标方位角，导致 heading_error 重新增大。迟滞确保机器人充分对齐后才开始前进。

#### 3. 行走 + 转向模式

```python
# 转向：tanh 非线性，平滑饱和
ω = turn_speed × tanh(2.0 × heading_error)

# 前进速度：距离衰减 × 朝向惩罚
heading_penalty = cos(heading_error)     # 1.0@0°, 0.5@60°, ≥0.15
if distance > decel_distance:            # 0.5m
    vx = fwd_speed × heading_penalty     # 全速区
else:
    factor = (distance / decel_distance)²  # 二次减速
    vx = fwd_speed × factor × heading_penalty
```

**朝向惩罚** `cos(heading_error)`：朝向偏差大时降速，确保机器人优先转向对齐，避免以错误方向高速行走导致收敛失败。

### 死区地板（Dead Zone Floor）

RL 策略对前进速度存在最小感知阈值（~0.25 m/s）。低于此值的指令被忽略，导致机器人在接近目标时停止不动。为解决此问题，所有非到达状态下的前进指令都强制 ≥ `min_fwd_speed`（0.25 m/s）。

```
          滤波前 cmd_raw
              │
              ▼
    cmd = α × cmd_raw + (1-α) × last_cmd    ← 低通滤波
              │
              ▼
    if cmd[0] > 0.01 and distance > arrival_threshold:
        cmd[0] = max(cmd[0], min_fwd_speed)  ← 地板：确保高于死区
```

地板在**低通滤波之后**生效，确保冷启动第一步（`last_cmd = 0`）也不会跌入死区。机器人以 0.25 m/s 的爬行速度逐步靠近，一旦距离 < 0.10m 立即停止。

### 最终对齐

```python
if distance < align_distance:  # 0.35m
    ω = turn_speed × tanh(3.0 × heading_error)  # 增强转向增益
```

靠近目标时不降低前进速度（原来会乘 `align_factor`，导致跌入死区），只增强转向响应以确保精准对齐。

### 完整控制框图

```
                    ┌──────────────────────────────────────────┐
                    │              Navigator.update()           │
                    │                                          │
    (x,y,yaw) ──►  │  distance < 0.10m?  ──YES──► cmd = 0     │
                    │       │ NO                               │
                    │       ▼                                  │
                    │  |heading_err| > 60°?                    │
                    │    YES: vx=0, ω=±turn_speed (原地转身)    │
                    │    NO:  进入行走模式                      │
                    │       │                                  │
                    │       ▼                                  │
                    │  ω = turn_speed × tanh(2×heading_err)    │
                    │  vx = fwd_profile × cos(heading_err)     │
                    │       │                                  │
                    │       ▼                                  │
                    │  distance < 0.35m?                       │
                    │    YES: ω = turn_speed × tanh(3×h_err)   │
                    │       │                                  │
                    │       ▼                                  │
                    │  cmd = α×cmd_raw + (1-α)×last_cmd        │
                    │  cmd[0] = max(cmd[0], min_fwd_speed)     │
                    └──────────────────────────────────────────┘
                                       │
                                       ▼
                                  cmd = [vx, 0, ω]
```

### 参数表

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `fwd_speed` | 0.7 m/s | 最大前进速度 |
| `turn_speed` | 1.0 rad/s | 最大转向角速度 |
| `arrival_threshold` | 0.10 m | 判定到达的距离阈值 |
| `decel_distance` | 0.5 m | 开始减速的距离 |
| `align_distance` | 0.35 m | 增强转向对齐的距离 |
| `min_fwd_speed` | 0.25 m/s | 前进速度地板（策略死区下限） |
| `alpha` | 0.7 | 低通滤波器系数 |

### 关键设计决策

| 决策 | 理由 |
|------|------|
| 死区地板在滤波**后**生效 | 确保冷启动第一步不跌入死区 |
| 迟滞（60°进入 / 45°退出） | 防止后方近距离目标的转身↔行走振荡 |
| 朝向惩罚 `cos(θ)` | 朝向偏差大时降速，优先转向 |
| 对齐区不缩放 vx | 缩放会导致速度跌入死区 |
| tanh 转向 | 小偏差线性响应，大偏差平滑饱和，无硬切换 |
| 二次减速 `(d/d₀)²` | 速度随距离平滑衰减 |
| 爬行逼近 `min_fwd_speed` | 机器人以 0.25 m/s 恒定低速逼近 0.10m 圈，不会早停 |
